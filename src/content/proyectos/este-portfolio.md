## Por qué Astro

Quería un sitio **rápido**, que enviara el mínimo JavaScript posible y que pudiera administrar sin tocar código.

## Cómo está hecho

- Páginas y componentes `.astro`.
- Proyectos como **Content Collections** validadas con Zod.
- Estilos con Tailwind CSS 4.
